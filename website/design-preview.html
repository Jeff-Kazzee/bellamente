Your agent remembers. Now you can see how.

Bellamente is living memory that runs on your machine: every fact your agent recalls is visible, scored, and yours to correct — and nothing ever leaves your computer.

Free & open source · macOS and Linux builds coming soon

Memory with grace, evidence, and consent

See every recall

When your agent answers, Bellamente shows which memories fed that answer — with similarity scores, latency, and what fell below the floor. The trace is the product.

Correct without erasing

Edit a memory and the old version stays in its history. Forgetting is reversible, deleting is explicit, and nothing is ever silently overwritten.

Yours, locally

One binary. Embedded Postgres and local embeddings. Binds to 127.0.0.1 by default. No account, no cloud, no telemetry.

Memory for any chat client, with zero code changes

Point your OpenAI-compatible client at bella instead of your model server. Bellamente injects the right memories on the way in and records a trace on the way out — your app never knows it got smarter.

1 your agent → bella :8080/v1
2 + memories injected · trace recorded
3 → your local model (Ollama, LM Studio, vLLM…)

Running in under a minute

Download one file, set one key, start. First run downloads a local embedding model — after that, everything works offline. The dashboard shows every memory and every trace.

# 1. set your key (any secret string)
export BELLA_API_KEY=your-secret

# 2. start the memory server
./bella serve
bellamente listening on 127.0.0.1:8080

# 3. open the dashboard
http://127.0.0.1:8080

The trace is the product

Every recall is durably logged: what was searched, what matched, at what score, in how many milliseconds — and what fell below the floor.

GET /inspect → scores, latency, provenance
CORRECT

Nothing silently overwritten

Edits create new versions with the old ones kept in the chain. Forgetting is reversible and audited. Hard delete is the only eraser, and it says so.

PATCH /memories/:id → v2 (v1 kept)
LOCAL

Your machine is the cloud

Embedded Postgres + pgvector, local embedding models, loopback binding by default. There is no server to trust because there is no server.
